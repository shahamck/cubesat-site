# What are CubeSats — NASA × B1T

A scroll-driven guide to CubeSats. A procedural Three.js 1U CubeSat tilts, opens up and explodes into its subsystems as you scroll, with callouts for each part. It is followed by real NASA CubeSat missions, a form-factor viewer, stats, news, events and a contact form.

Portfolio concept. Not an official NASA website.

## Run

```bash
npm install
npm run dev
```

Built with Vite, Three.js and Lenis. Deployed to GitHub Pages by `.github/workflows/deploy.yml` on every push to `main`.
